# TerraSmart Destek

TerraSmart's RustDesk build for the VERA tablets. It is RustDesk with a few changes, kept as
small as possible so every upstream release can be followed:

| Change | Where |
|---|---|
| Package `tr.com.terrasmart.rustdesk`, name "TerraSmart Destek" (installs next to the field's `com.carriez.flutter_hbb`, whose signing key is lost) | `flutter/android/app/build.gradle`, `AndroidManifest.xml` |
| versionCode = upstream code × 100 + TerraSmart revision | `flutter/android/app/build.gradle` |
| `rustdesk.terrasmart.com.tr` and its key built in; update check and scam warning fixed off | `libs/hbb_common` → `terrasmarttechnology/hbb_common`, branch `terrasmart-<version>` |
| Preset permanent password from the secret `TERRASMART_RUSTDESK_PASSWORD` (the build gets only `"00" + base64(sha256(password + salt))`; a password set on a tablet still wins) | `libs/hbb_common` (`HARD_SETTINGS`), `make-android-workflow.py` |
| Android-only build signed with `terrasmart-rustdesk.jks` | `.github/workflows/terrasmart-android.yml`, generated by `make-android-workflow.py` |

Updates reach the tablets only through Headwind (panel › Sürümler), never from the app itself.

## Building

Actions › **TerraSmart Destek Android** › Run workflow (branch `terrasmart`, revision `0`, or 1, 2,
… for a TerraSmart fix on the same upstream version). It stops if the signing secrets are missing,
checks every APK carries the certificate `b86ff2fa…2dec37`, and publishes the release
`destek-<version>-r<revision>`. Upload `rustdesk-<version>-universal-signed.apk` in the panel.

## Moving to a new RustDesk release

The upstream watch workflow opens an issue when RustDesk releases. Then, with `upstream` =
`https://github.com/rustdesk/rustdesk` and `libs/hbb_common`'s `upstream` =
`https://github.com/rustdesk/hbb_common`:

```sh
NEW=1.5.1   # the new upstream tag
git fetch upstream tag $NEW --no-tags
HB=$(git rev-parse "$NEW:libs/hbb_common")

# hbb_common: the TerraSmart commit on the commit this release uses
cd libs/hbb_common
git fetch upstream && git fetch origin
OURS=$(git rev-parse HEAD)                     # current terrasmart-<old> commit
git checkout -B terrasmart-$NEW $HB && git cherry-pick $OURS
git push origin terrasmart-$NEW
cd ../..

# rustdesk: the TerraSmart commits on the new tag
OLD=$(sed -n 's/^  VERSION: *//p' .github/workflows/terrasmart-android.yml)
git checkout -B terrasmart-$NEW $NEW
git cherry-pick $(git rev-list --reverse $OLD..terrasmart)
# The first pick stops on libs/hbb_common (both sides moved it); point it at ours:
#   git -C libs/hbb_common checkout terrasmart-$NEW && git add libs/hbb_common && git cherry-pick --continue
python3 terrasmart/make-android-workflow.py
git commit -am "Move TerraSmart Destek to RustDesk $NEW"
git push origin terrasmart-$NEW
```

Build `terrasmart-$NEW`, try it on the VERA Development tablets, then make it the `terrasmart`
branch (`git push -f origin terrasmart-$NEW:terrasmart`).
